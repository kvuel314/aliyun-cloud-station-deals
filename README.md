## 新老用户资格怎么算？这里最容易踩坑

云小站活动的参与门槛是：阿里云官网已实名认证的注册会员。注意“官网”的范围不包括阿里云国际站（alibabacloud.com）和日本站（jp.aliyun.com），在国际站买过东西，不影响你在国内站参加活动。

**新用户**的定义是：在阿里云官网没有收费云产品购买记录的会员。这里有个多数人搞错的细节——阿里云对“云产品”的界定排除了域名、虚拟主机和云市场产品。也就是说，如果你只是买过域名，账号里没有云服务器、云数据库这类收费订单，你仍然算新用户。同理，只申请过免费试用也不影响资格，因为“购买记录”指的是付费订单。

**老用户**就是有收费云产品购买记录的账号。ECS老用户在“爆款产品5折起”专区可以按优惠价购买ECS，限购1单，每单最多3台。

还有一条规则专门防“多开账号”：阿里云通过证件、手机号、支付账号、设备、收货地址等关联信息判断“同一用户”，同一用户名下的多个账号互为同人账号。用小号重复领新用户优惠属于明确禁止的行为，查实后平台有权收回权益、取消资格、撤销违规交易，必要时追究法律责任。新用户还有数量限制：活动期间可享受的活动优惠仅限1单1件，一次下单吃不满多台服务器的优惠。

## 秒杀、新用户专享、新老同享三类活动怎么玩

云小站的产品按购买资格分三类，规则各不相同：

1. **秒杀产品**：每天上午10点更新库存，抢完即止。参与条件并非“必须新用户”，门槛是“之前没买过该类产品”——老用户只要没买过对应品类，同样能抢。
2. **新用户专享**：同一用户生命周期内限购1次。这个“1次”是终身的，不是每次活动各来一次，买之前想清楚选哪款。
3. **新老用户同享**：不区分新老用户，但该专区里的对象存储OSS产品无法申请线上退款，下单前留意。

三个专区可以配合着用：先用免费试用确认产品满足需求，再去新用户专享或秒杀里选，最后叠代金券。有个例外要记住：存储类秒杀产品禁止使用优惠券，而且云小站所有存储产品活动（SCU除外）每个账号限参与一次。

## 下单前必须知道的几条限制

最要紧的一条是退订：

> 除特殊情况外，参加云小站活动购买的产品和提货券不支持退订。确因特殊原因退订的，退订前需要交回通过活动享受的权益——补足差价、退还已使用的代金券金额、交回奖品等。

这条规则的实际影响是：下单前要按“确定用满这个时长”来做决定，“先买着、不合适再退”在活动产品上行不通。1年的服务器按活动价确实便宜，但项目要是三个月就结束，这笔钱基本沉没。

其余几条也值得过一遍：

- **优惠不叠加**：云小站活动不与其他活动或优惠同时使用，比价时别把两边的折扣加在一起算；
- **规则可调整**：阿里云可以根据实际情况修改活动规则，公布在活动页面上即时生效，调整前已获得的权益不受影响；
- **活动名称仅供参考**：具体以你打开活动页时展示的规则为准，这一点官方明确写在了规则里。

## 云小站活动常见问题

**云小站是官方的吗？**
是。云小站运行在阿里云官网域名下，是阿里云官方的优惠聚合与分销入口，订单和售后都走官方体系，这和找第三方代办是两回事。

**老用户还能在云小站买到便宜服务器吗？**
能，路径有两条：一是“爆款产品5折起”专区（限购1单、每单最多3台），二是秒杀——只要之前没买过该类产品，老用户也能参与抢购。

**只买过域名，还算新用户吗？**
算。域名、虚拟主机、云市场产品的购买记录不计入“云产品”，只要没有云服务器、云数据库这类收费云产品订单，账号仍按新用户对待。

**云小站的价格一定是最低价吗？**
不一定。云小站价本身不与其他优惠叠加，但大促期间（618、双11、采购季）云小站自己会上新力度更大的专属券。稳妥的做法是大促节点和平时各看一次页面价格，算上能领的券再决定。
